# Manufacturing Production & Quality Analytics

## Project Overview
This project analyzes simulated manufacturing production data using Python, Pandas, MySQL, SQL, and Matplotlib.

## Objectives
- Analyze machine-wise production performance.
- Calculate production efficiency and production loss.
- Analyze product defects and machine downtime.
- Retrieve and analyze data stored in MySQL.
- Visualize machine-wise production efficiency.

## Tools & Technologies
- Python
- Pandas
- MySQL
- SQL
- Matplotlib
- Visual Studio Code

## Dataset
The project uses 1,000 simulated manufacturing production records.

The dataset includes:
- Production ID and date
- Machine name and part name
- Target and actual production
- Defect quantity
- Downtime in minutes

**Note:** This is simulated data created for learning and portfolio purposes. It is not real factory data.

## Analysis Performed
- Machine-wise production summary
- Production efficiency percentage
- Production loss calculation
- Defect rate percentage
- Downtime analysis
- Machine efficiency bar chart

## Project Status
Python data generation, MySQL data loading, SQL analysis, and Python-based visualization completed.
